Like Local 로고 파일 안내
========================

1_SVG  (가장 권장 - 크기를 키워도 깨지지 않음, 인쇄용)
  likelocal-logo-black.svg     가로형 로고, 검정 (밝은 배경용)
  likelocal-logo-white.svg     가로형 로고, 흰색 (진한 파란 헤더용)
  likelocal-symbol-black.svg   정사각형 심볼, 검정
  likelocal-symbol-white.svg   정사각형 심볼, 흰색

2_PNG  (배경 투명)
  likelocal-logo-black-1200.png / -600.png
  likelocal-logo-white-1200.png / -600.png
  likelocal-symbol-black-512.png
  likelocal-symbol-white-512.png

3_favicon  (브라우저 탭 아이콘)
  favicon.svg, favicon.ico, favicon-16.png, favicon-32.png, favicon-512.png
  apple-touch-icon.png (180px, 아이폰 홈 화면용)

  <head> 안에 넣을 코드 예시:
  <link rel="icon" href="/favicon.ico" sizes="any">
  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <link rel="apple-touch-icon" href="/apple-touch-icon.png">

참고
- 헤더(진한 파란색)에는 likelocal-logo-white.svg 를 그대로 올리면 됩니다.
  흰 상자 안에 넣을 필요가 없습니다. 침대 부분은 투명하게 뚫려 있습니다.
- 글씨체: DM Serif Display (SIL Open Font License, 상업적 사용 가능).
  글씨는 도형(아웃라인)으로 변환되어 있어 폰트 설치가 필요 없습니다.
